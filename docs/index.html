Stitch Export

Stitch Export is a free, open-source Chrome extension for Google Stitch that exports every project — screens, images, design systems and the full chat history — to ZIP archives and LLM-ready JSON (Claude, ChatGPT), locally in your browser.

Install from Chrome Web Store View source on GitHub

Whole account in one ZIP

Export All Projects bundles every project: screens, history, design systems and chat.

Full design history

Per-turn generated screens, so you can see how each design evolved.

LLM-ready JSON

Claude Code, OpenAI ChatGPT or custom-role conversation files.

Local and private

No third-party servers, no analytics. Everything is saved to your Downloads folder.

Install

Chrome Web Store: add Stitch Export to Chrome.

Load unpacked:

git clone https://github.com/nsozturk/stitch-export.git
# then open chrome://extensions, enable Developer Mode,
# click "Load unpacked" and select the cloned folder

Usage

Export All Projects

  1. Open any tab on stitch.withgoogle.com while logged in.
  2. Click the Stitch Export icon. The badge shows your project count.
  3. Press Export All Projects and pick a conversation format.
  4. One ZIP of every project is downloaded when the run finishes.

The export runs in the background: closing the popup does not stop it. Keep the background Stitch tab open until the download appears.

Export This Project (ZIP)

On a project page (stitch.withgoogle.com/projects/{ID}) press Export This Project (ZIP). You get the same layout as one project of Export All, plus a full-size picture of every HTML screen.

Export Conversation

Press Export Conversation to save the chat only, as a JSON file in the format you chose. No ZIP, no screens.

What's in the ZIP

ProjectName_<id>/
├── screens/                    final HTML screens + image-only screens (original resolution)
├── history/
│   └── turn-001-*/             screens generated in each turn
├── design-systems/             DESIGN.md docs (*.md)
├── chat.json                   every turn
└── conversation.<format>.json  chat in the chosen format

Export This Project (ZIP) adds a full-size picture of every HTML screen on top of this layout.

Privacy

  • The extension uses Stitch's own web API from your logged-in tab.
  • Nothing is sent to any third-party server. Exports are local downloads.
  • No analytics, no telemetry, no tracking.
  • Passwords and session tokens are never read or transmitted.

FAQ

How do I export all my Google Stitch projects?

Install Stitch Export, open any stitch.withgoogle.com tab, click the extension icon and press Export All Projects. One ZIP with every project is downloaded.

Can I export my Stitch chat history to Claude or ChatGPT format?

Yes. Choose Claude Code, OpenAI ChatGPT or a Custom format with your own user and assistant role names. The result is a conversation JSON file.

Does Stitch Export send my designs to a server?

No. It calls Stitch's own web API from your logged-in tab and saves files locally. Nothing is sent to any third-party server, and there is no analytics or telemetry.

Does the export stop if I close the popup?

No. The export runs in the background. Keep the background Stitch tab open until the ZIP is downloaded.

Is Stitch Export free and open source?

Yes. It is free, MIT licensed, and the source is on GitHub. It is an unofficial extension and is not affiliated with Google.
